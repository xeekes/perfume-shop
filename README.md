# Aura Parfums — Perfume Shop

React storefront for a perfume e-commerce site (Create React App).

## Stack

React 18, Redux, React Router, Sass, Swiper, Font Awesome

## Features

- Home: bestsellers, new fragrances, brands, fragrance picker
- Catalog with filters
- Product page (description and extra details)
- Cart and orders page
- Login, contacts, FAQ

## Getting started

```bash
npm install
npm start          # http://localhost:3000
npm run build      # production build → build/
```
